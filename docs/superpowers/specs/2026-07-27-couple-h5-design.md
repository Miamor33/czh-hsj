# 情侣 H5 应用设计文档

> 日期：2026-07-27  
> 项目：czh & hsj 个人情侣网页（类 Suki）  
> 状态：已确认

## 1. 目标

为情侣双方打造可嵌入微信订阅号菜单的 H5 应用。访客默认进入展示模式；仅双方凭密码进入正常模式，使用纪念日、相册、问答与恋爱挑战。

## 2. 产品决策

| 项 | 决策 |
|----|------|
| 受众 | 个人使用（仅一对情侣） |
| 入口 | 微信订阅号自定义菜单 → HTTPS H5 |
| 展示模式 | 恋爱天数、下一场纪念日、精选照片；不暴露问答/挑战 |
| 正常模式 | czh / hsj 各自密码登录（JWT） |
| 问答 | 按人作答；双方都答完才互看 |
| 挑战 | 「我们」共同完成；无个人进度 |
| 挑战模块 | ① 100 件小事 ② 走遍全国 70 城市 ③ 100 张电影票根 |
| 鉴权 | 仅密码；订阅号不做 OpenID |
| 技术 | Spring Boot 3 + Vue 3 + MySQL + 本地图片 |
| 部署 | 已有服务器；域名/HTTPS 后挂菜单 |

## 3. 信息架构

### 3.1 展示模式

- 品牌名（czh & hsj）
- 恋爱天数
- 下一场纪念日（名称 + 倒计时）
- 精选照片
- 低调登录入口

### 3.2 正常模式（底部 Tab）

1. **首页** — 天数、近期纪念日、挑战进度摘要、待答问答提示  
2. **相册** — 上传 / 列表 / 精选 / 删除  
3. **问答** — 题库、作答、筛选（待我答 / 待对方 / 已完成）  
4. **挑战** — 三模块切换、共同打卡（备注/配图）

## 4. 功能规则

### 4.1 纪念日

- `togetherDate`（在一起日期）用于计算恋爱天数  
- 多条纪念日：名称、日期、是否每年重复  
- 展示模式只读「下一场」；登录可 CRUD  

### 4.2 相册

- 登录上传（jpg/png/webp，大小限制）  
- `featured=true` 出现在封面（建议上限 12）  
- 展示模式仅精选  

### 4.3 问答

- 预置题 + 自定义加题  
- `qa_answer(partner_id, question_id)` 独立作答  
- 双方均有答案后才返回对方答案内容  

### 4.4 恋爱挑战

- 三模块共用「共同完成」模型  
- 完成记录：时间、操作者、可选备注与配图  
- 进度仅统计共同完成数；展示模式不可见  

## 5. 技术架构

```
微信浏览器 → Nginx → Vue 静态资源
                   → /api → Spring Boot → MySQL
                                      → 本地 uploads/
```

- 公开 API：`GET /api/public/cover`  
- 登录：`POST /api/auth/login`（partnerKey + password）→ JWT  
- 密码：BCrypt；上传文件名随机化  

### 5.1 核心表

`partner`、`setting`、`anniversary`、`photo`、`qa_question`、`qa_answer`、`challenge_module`、`challenge_item`、`challenge_completion`

## 6. 安全

- JWT 过期；登录失败简单限流  
- 上传类型/大小校验，防路径穿越  
- 公开接口字段最小化  
- 密码不进仓库明文（环境变量 / 本地配置）  

## 7. MVP 范围外

- 微信 OpenID / 模板消息 / 支付  
- 多对情侣、邀请注册、社交分享  
- 实时聊天、地图轨迹、OSS、原生 App  

## 8. 部署

1. 服务器：JDK 17+、MySQL、Nginx  
2. 开发期可用 IP + HTTP  
3. 上线：域名 + HTTPS，订阅号菜单指向站点根路径
